# Структура Google Таблицы заказов для Candy_Ksendy

Этот документ содержит готовую спецификацию структуры, цветового кодирования и логики работы Google Таблицы, которая выступает в качестве CRM-системы для кондитера Ксении. Вы можете использовать эту спецификацию как техническое задание для ИИ-разработчика (Claude Code / Google AI Studio) и как руководство по ручной настройке таблицы.

---

## 1. Архитектурная концепция: «Заказ как Заявка»
В кондитерском бизнесе на заказ мгновенное автоматическое принятие заказа невозможно из-за ручных проверок (загруженность кухни, наличие редких ягод, здоровье кондитера, форс-мажоры). 

Поэтому таблица работает по принципу **«Заявка на согласовании»**:
1. Клиент собирает десерт и отправляет форму.
2. В таблицу добавляется строка со статусом **`⏳ На согласовании`** (это «прелюдия»).
3. Ксения получает уведомление в Telegram, созванивается или списывается с клиентом.
4. В процессе общения Ксения:
   * Подтверждает дату и время.
   * Проверяет ингредиенты на складе.
   * Обсуждает размер предоплаты.
5. Только после получения предоплаты Ксения вручную меняет статус в таблице на **`✅ Подтвержден`**.

## 2. Структура столбцов таблицы (Шапка)

При создании таблицы оформите первую строку (A1:N1) жирным шрифтом на светло-бежевом или кремовом фоне (в стиле бренда) и закрепите её (`Вид ➔ Закрепить ➔ 1 строку`).

| Столбец | Название столбца | Формат данных | Описание / Пример заполнения | Источник данных |
| :---: | :--- | :--- | :--- | :--- |
| **A** | **ID Заявки** | Текст | `#ck-9f82` (короткий хэш заказа) | Генерируется бэкендом |
| **B** | **Дата подачи** | Дата и время | `21.08.2026 13:45` | Генерируется бэкендом |
| **C** | **Клиент** | Текст | `Иван Петров` | Вводит клиент |
| **D** | **Телефон** | Телефон | `+7 (999) 123-45-67` | Вводит клиент |
| **E** | **Telegram** | Текст | `@ivan_vibe` | Вводит клиент (или авто-Mini App) |
| **F** | **Категория** | Текст | `Торт` / `Бенто-торт` / `Капкейки` | Выбор в конструкторе |
| **G** | **Конструктор (Детали)** | Текст | `Бисквит: Шоколад; Крем: Чиз; Начинка: Вишня` | Выбор в конструкторе |
| **H** | **Объем / Кол-во** | Текст | `2.5 кг` / `Набор 6 шт.` | Выбор в конструкторе |
| **I** | **Декор и пожелания**| Текст | `Надпись "С днем рождения!", ягодный венок` | Вводит клиент в поле формы |
| **J** | **Дата выдачи** | Дата и время | `25.08.2026 15:00` | Выбирает клиент |
| **K** | **Расчетная цена** | Финансовый | `5 400 ₽` | Считается автоматически в коде |
| **L** | **Предоплата** | Процент / Число | `50%` (или сумма в рублях) | Вносится Ксенией вручную |
| **M** | **Статус** | Выпадающий список | `⏳ На согласовании` (по умолчанию) | Выбирается Ксенией вручную |
| **N** | **Заметки кондитера** | Текст | *«Купить пищевое золото, клиент просил без мяты»*| Вносится Ксенией вручную |

## 3. Настройка выпадающего списка статусов (Dropdown)

Для столбца **M (Статус)** настройте «Умный выпадающий список» через `Данные ➔ Настройка данных ➔ Добавить правило`.

### Варианты статусов и цветовое кодирование:

| Статус | Цвет плашки | Смысловое значение для Ксении |
| :--- | :--- | :--- |
| **`⏳ На согласовании`** | 🟡 Желтый | Заказ только что прилетел с сайта. Нужно связаться, проверить календарь и обсудить предоплату. |
| **`✅ Подтвержден`** | 🟢 Зеленый | Ксения согласовала детали, предоплата получена. Торт официально в календаре выпечки. |
| **`👩‍🍳 Выпекается`** | 🟣 Фиолетовый | Процесс запущен: бисквиты в духовке, крем взбивается, декор собирается. |
| **`🍓 Готов к выдаче`** | 🔵 Синий | Десерт собран, упакован в коробку и ждет в холодильнике самовывоза. |
| **`🎉 Выдан`** | ⚫ Серый | Клиент забрал десерт, оплатил остаток. Сделка успешно закрыта. |
| **`❌ Отклонен`** | 🔴 Красный | Форс-мажор, дата занята или клиент передумал на этапе созвона. |

## 4. Что нужно предоставить Claude Code для интеграции бэкенда с таблицей?

Для того чтобы **Claude Code** (или другой ИИ) правильно написал бэкенд-код интеграции, ему **НЕ НУЖНО давать вашу реальную секретную ссылку на таблицу или приватные ключи**. 

Вы должны передать ему следующие **3 вещи**:

1.  **Названия переменных окружения (Environment Variables)**, которые код будет использовать. Claude пропишет их вызовы, а вы вставите реальные значения позже в панели Vercel:
    *   `GOOGLE_SPREADSHEET_ID` — уникальный ID таблицы (строка из ссылки).
    *   `GOOGLE_SERVICE_ACCOUNT_EMAIL` — email созданного вами сервисного робота.
    *   `GOOGLE_PRIVATE_KEY` — секретный ключ сервисного робота.
2.  **Точную схему столбцов (Маппинг)**. Вы должны дать ИИ инструкцию, в какую колонку отправлять конкретное поле. Например:
    > *«Claude, write the google sheets integration script. Column A must receive the generated Order ID, Column B receives the current Date, Column C receives `client.name`, Column D receives `client.phone`, ... and Column M must default to the text '⏳ На согласовании'»*.
3.  **Имя листа**. По умолчанию в новых таблицах лист называется `Лист1` (или `Sheet1` в английской версии). Сообщите ИИ, как называется лист, чтобы он не выдал ошибку `Range not found`.

## 5. Инструкция для ИИ по бесконфликтной записи (App-Safe Writing)
При генерации кода проследите, чтобы ИИ использовал метод **`append`** (добавление в конец) библиотеки Google Sheets API. 

*   **Почему это важно:** Метод `append` автоматически находит первую абсолютно пустую строку в таблице и записывает данные туда.
*   **Безопасность ручной работы:** Если Ксения будет вручную писать комментарии в столбце **N («Заметки кондитера»)** или изменять статус в столбце **M**, бэкенд-код при следующем заказе никогда не перетерпит её записи. Новый заказ просто запишется строчкой ниже.
