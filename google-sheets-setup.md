# Шпаргалка: Настройка Сервисного аккаунта Google Cloud для интеграции с Google Таблицами

Эта пошаговая инструкция поможет тебе настроить безопасный доступ приложения **Candy_Ksendy** к Google Таблицам без необходимости авторизации через личные аккаунты пользователей.

---

## Шаг 1. Создание проекта в Google Cloud Console

1. Перейди на портал [Google Cloud Console](https://console.cloud.google.com/).
2. Войди под своим Google-аккаунтом.
3. В верхнем левом углу (рядом с логотипом Google Cloud) нажми на выпадающий список проектов и выбери **"New Project"** (Новый проект).
4. Укажи понятное имя проекта, например: `candy-ksendy-sheets-app`.
5. Нажми **"Create"** (Создать) и подожди несколько секунд, пока проект создаётся. После создания обязательно выбери его в списке активных проектов вверху экрана.

---

## Шаг 2. Включение Google Sheets API

Для того чтобы проект мог взаимодействовать с таблицами, нужно активировать соответствующий интерфейс:

1. В верхней строке поиска введи **"Google Sheets API"**.
2. Выбери этот API в результатах поиска.
3. На открывшейся странице нажми синюю кнопку **"Enable"** (Включить).
4. *Рекомендация:* Для стабильной работы также найди через поиск **"Google Drive API"** и тоже нажми **"Enable"** (это позволит боту корректно определять доступ к файлам на диске).

---

## Шаг 3. Создание Сервисного аккаунта (Service Account)

Сервисный аккаунт — это специальный "виртуальный бот", от лица которого наше приложение будет вносить данные в таблицу Ксении.

1. Открой главное меню (три полоски в левом верхнем углу) ➔ **"IAM & Admin"** (Управление доступом) ➔ **"Service Accounts"** (Сервисные аккаунты).
2. Нажми кнопку **"Create Service Account"** в верхней панели.
3. Заполни основные поля:
   * **Service account name:** введи имя, например, `sheets-editor`.
   * **Service account ID:** сгенерируется автоматически на основе имени (например, `sheets-editor@candy-ksendy-sheets-app.iam.gserviceaccount.com`).
   * **Service account description:** можно оставить пустым или написать *«Бот для записи заказов Candy Ksendy»*.
4. Нажми **"Create and Continue"** (Создать и продолжить).
5. Шаг назначения ролей проекта (**Grant this service account access to project**) и доступ пользователей можно просто пропустить, нажав **"Continue"**, а затем **"Done"**.

---

## Шаг 4. Создание и скачивание секретного JSON-ключа

Теперь нужно получить пароль, с помощью которого код бэкенда подтвердит свою личность.

1. В списке сервисных аккаунтов найди только что созданный e-mail.
2. В крайней правой колонке "Actions" нажми на **три точки** и выбери **"Manage keys"** (Управлять ключами).
3. Нажми кнопку **"Add Key"** ➔ **"Create new key"** (Создать новый ключ).
4. Выбери формат **JSON** (он выбран по умолчанию) и нажми **"Create"** (Создать).
5. Файл приватного ключа автоматически скачается на твой компьютер (имя файла будет выглядеть как-то так: `candy-ksendy-sheets-app-xxxxxxxxx.json`).

> ⚠️ **ВАЖНО:** Храни этот файл в надёжном месте. Это единственный экземпляр ключа доступа! Не загружай его на GitHub в открытом виде.

---

## Шаг 5. Предоставление доступа к Google Таблице Ксении

Чтобы наш бот имел право писать в таблицу Ксении, Ксения должна выдать ему доступ, как обычному человеку.

1. Скопируй длинный e-mail сервисного аккаунта (который мы создали на Шаге 3). Он выглядит так: `sheets-editor@candy-ksendy-sheets-app.iam.gserviceaccount.com`.
2. Ксения (или ты) создаёт обычную Google Таблицу для учёта заказов.
3. В правом верхнем углу таблицы нажимаете кнопку **"Поделиться"** (Share).
4. В поле ввода адреса почты вставьте скопированный e-mail сервисного аккаунта.
5. Установите роль **"Редактор"** (Editor).
6. Снимите галочку *"Уведомить пользователей"* (так как боту всё равно некуда отправлять письмо) и нажмите **"Поделиться"** (Share).

Теперь сервисный аккаунт имеет полное право удалённо открывать эту таблицу и дописывать туда строки!

---

## Шаг 6. Настройка переменных окружения (Environment Variables) на Vercel

Чтобы безопасно использовать этот ключ в облаке Vercel, мы скопируем его данные:

1. Открой скачанный `.json` файл любым текстовым редактором (Блокнот, VS Code).
2. Скопируй всё его содержимое (весь текст в фигурных скобках `{...}`).
3. В личном кабинете **Vercel** зайди в настройки своего проекта ➔ **Settings** ➔ **Environment Variables**.
4. Создай новую переменную:
   * **Key:** `GOOGLE_SERVICE_ACCOUNT_KEY`
   * **Value:** вставь скопированный текст JSON-файла целиком.
5. Также создай переменную для ID твоей Google Таблицы:
   * **Key:** `GOOGLE_SHEETS_SPREADSHEET_ID`
   * **Value:** скопируй ID из ссылки твоей таблицы (это длинный набор символов между `/d/` и `/edit` в адресной строке браузера).

---

**Готово!** Твой серверный код (GCP Cloud Function) при получении заказа прочитает переменную `GOOGLE_SERVICE_ACCOUNT_KEY`, авторизуется в Google Sheets API под именем сервисного аккаунта и мгновенно запишет данные в таблицу с ID `GOOGLE_SHEETS_SPREADSHEET_ID`. Ксения увидит новый заказ в ту же секунду!
